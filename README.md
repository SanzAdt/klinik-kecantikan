# MAISON LUMINA — Luxury Aesthetic & Dermatology Clinic Portal

Official patient web showcase for modern medical dermatology & regenerative aesthetic clinic.

## ✨ Fitur Unggulan
- **Responsive Mobile-First Luxury Design:** Optimal di seluruh layar (iPhone, Android, Tablet, Desktop).
- **Digital Facial Skin Scanner:** Simulasi interaktif diagnosis zona wajah (Dahi, Pipi, Dagu/Rahang, Bawah Mata).
- **Interactive Cost Calculator:** Perhitungan estimasi investasi perawatan secara transparan dan instan.
- **Doctor Shift & VIP Booking Engine:** Reservasi slot konsultasi dokter spesialis terintegrasi langsung dengan WhatsApp Concierge.
- **Zero-Latency Performance:** Pure modern HTML5/CSS3/Vanilla JavaScript tanpa dependensi eksternal yang memberatkan.
